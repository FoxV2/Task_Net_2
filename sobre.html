Sobre o TaskNet

O TaskNet é uma plataforma web de gerenciamento de tarefas pessoais e acadêmicas, desenvolvida como Projeto Integrador III do curso de Tecnologia em Sistemas para Internet do IFSul – Campus Pelotas (Polo Rosário do Sul).

Tecnologias utilizadas

  • HTML5 + CSS3
  • JavaScript (ES6+)
  • Bootstrap 5.3 (framework front-end)
  • Bootstrap Icons
  • localStorage como persistência simulada

Funcionalidades principais

  • Cadastro e autenticação de usuários
  • Proteção de rotas (páginas restritas a usuários logados)
  • CRUD completo de tarefas (criar, listar, editar, concluir, excluir)
  • Filtro de tarefas por status
  • Estatísticas na página inicial
  • Interface responsiva e com cuidados de acessibilidade (WCAG)

Preparado para backend real: A estrutura de dados e as funções de persistência foram abstraídas, facilitando a futura integração com API e banco de dados relacional.
